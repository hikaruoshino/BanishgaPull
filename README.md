## 🌟 主な特徴・機能 (v2.0.3 修正版)

- **HUD表示の文字化け完全解消**:
  画面オーバーレイ描画からチャット用制御コード () を除去し、視認性の高いクリーンな文字表示を実現。
- **高精度3D距離計算**:
  自分 (me) の座標 (X, Y, Z) と対象モンスターの座標からリアルタイム高精度直線距離 (メートル) を動的算出。
- **現在ターゲット (<t>) のリアルタイム距離表示**:
  カーソルでターゲット中の敵の距離も画面上に分かりやすく表示。
- **指定釣り役 (Designated Puller) 最優先追跡**:
  指定した釣り役メンバーが被弾・交戦中の敵を最優先で検知し、バニシュガ等で瞬時にヘイトを横取り・キャッチ。
- **設定の完全永続化 ()**:
  指定釣り役名、使用魔法、索敵距離、HUD位置などが自動保存され、エリアチェンジや再読み込みでリセットされません。
