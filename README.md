# BanishgaPull (FF11 Windower4 Addon)

[ English | [日本語](#日本語) ]

---

## English

An automated target-acquisition and instant Banishga casting addon for Windower 4 in *FINAL FANTASY XI*.

### 🌟 Key Features
- **Puller-Proximity Target Priority**: Scans and targets the enemy closest to your designated puller.
- **Smart Filtering**: Filters out town NPCs, Auction Counters, Luopans, and party pets, while correctly targeting enemy avatars.
- **Zero Subtarget Lag**: Instant target lock and Banishga execution without `<stnpc>` delays.

### ⚙️ Commands & Macro Examples
- `/console bp` : Instantly targets best enemy and casts Banishga.
- `/console bp puller <t>` : Sets targeted party member as puller.
- `/console bp puller reset` : Resets puller setting to auto party mode.
- `/console bp status` : Checks current puller status in chat.
- `/console bp ?` : Displays in-game help menu.

## 日本語

FF11 Windower4 用のターゲット捕獲＆自動バニシュガ詠唱アドオンです。

### 🌟 主な特徴
- **釣り役最接近敵の優先ターゲット**: 指定した釣り役に最も近く群がっている敵を自動選出してバニシュガを即時詠唱。
- **誤ターゲット防止**: 街のNPCや競売カウンター、味方ペット・羅盤を除外し、敵モンスター・敵召喚獣のみを検出。
- **サブターゲットラグの排除**: ボタン一発でターゲット固定からバニシュガ発動までを即座に完了。

### ⚙️ コマンド＆マクロ登録例
- `/console bp` : 最優先敵を選択してバニシュガ即時詠唱。
- `/console bp puller <t>` : ターゲット中の味方を釣り役に指定。
- `/console bp puller reset` : 釣り役指定を解除。
- `/console bp status` : 設定状況を確認。
- `/console bp ?` : コマンドヘルプを表示。
