# BanishgaPull (v2.1.0)

**ファイナルファンタジーXI（Windower 4用） タゲ横取り＆釣り補助アドオン**

`BanishgaPull` は、FFXI Windower 4 向けの高速ターゲット補獲・詠唱補助アドオンです。ダイバージェンス、オメン、オデシー（シェオル）、各種範囲狩りや多重リンクなどの集団戦において、指定した「釣り役」の周囲に集まった敵や、PTメンバーを攻撃している敵を自動で優先検索し、`バニシュガ` や `ディアガ` などの範囲・単体魔法を瞬時にターゲット＆詠唱します。

v2.1.0 では、**ヘイトが発生する前の「黄色ネーム（リンク・引連れ中の敵群）」への即時対応**および**釣り役基準の距離判定最適化**を実施しました。

---

## 🌟 主な機能

* **4段階の自動ターゲット優先度判定（v2.1 黄色ネーム対応）**
  * **Priority 4（最高）**: 指定釣り役を直接攻撃・ターゲットしている敵（赤ネーム）
  * **Priority 3（新設）**: 指定釣り役の周囲15m以内にいる敵（ヘイト未発生の黄色ネーム・引連れ群）
  * **Priority 2**: 他のパーティメンバーを攻撃している敵（赤ネーム）
  * **Priority 1**: 自分から20m以内にいるその他の有効なNPC
* **指定釣り役（Puller）追尾＆距離ソート**
  * `//bp set <キャラ名>` で指定した釣り役の足元・周辺にいる敵を「釣り役からの距離」で最優先ソートし、大量の敵群から最も近い個体を一瞬で捉えます。
* **設定の自動保存 (`libs/config.lua`)**
  * 釣り役設定、使用魔法、検索半径、HUD位置などの設定は `data/settings.xml` に自動保存され、エリアチェンジや再読み込み後も保持されます。
* **リアルタイム DirectWrite HUD (`libs/texts.lua`)**
  * 現在の釣り役、選択魔法、検索半径、ターゲット名、自分および釣り役からの距離を画面上にリアルタイム表示します（日本語UTF-8表示対応）。
* **使用魔法のカスタム変更**
  * `Banishga`、`Banishga II`、`Diaga`、`Dia`、`Poisonga` など、任意の魔法名を `//bp spell <魔法名>` で簡単に切り替え可能です。
* **クライアント安定性**
  * アンロード時やエリアチェンジ時のイベントリソース解除処理を徹底し、メモリリークやPOLクラッシュを起こさない安全設計です。

## 🚀 インストール方法

1. 最新の `BanishgaPull` ファイルを入手します。
2. Windower 4 の addons フォルダー内に `BanishgaPull` フォルダーを作成し、配置します：
   `Windower4/addons/BanishgaPull/BanishgaPull.lua`
3. ゲーム内のコンソールまたはマクロで読み込みます：
   `//lua load BanishgaPull`

---

## 💻 コマンド一覧 (`//bp` または `//banishgapull`)

| コマンド | 説明 | 実行例 |
| :--- | :--- | :--- |
| `//bp` または `//bp pull` | 最優先ターゲットを検索し、設定中の魔法を自動詠唱 | `//bp` |
| `//bp set <キャラ名>` | 最優先で横取り・保護する「指定釣り役」を設定 | `//bp set Taro` |
| `//bp set reset` | 釣り役指定を解除（PT全員の被弾自動検知モードへ切り替え） | `//bp set reset` |
| `//bp spell <魔法名>` | 詠唱する魔法を変更 | `//bp spell Diaga` |
| `//bp dist <メートル>` | 最大検索半径を設定（5.0 〜 30.0m） | `//bp dist 18` |
| `//bp hud` | 画面上の HUD 表示 ON/OFF 切り替え | `//bp hud` |
| `//bp status` | 現在の設定状態をチャット欄に表示 | `//bp status` |

## 🎯 ターゲット優先度検索ロジック (v2.1.0)

`//bp` 実行時、自分から最大検索半径（デフォルト20m）以内にいる全NPCを以下の順序で判定します。

1. **Priority 4 (最高)**: 指定釣り役を直接攻撃している敵（赤ネーム）
2. **Priority 3**: 指定釣り役の周囲15m以内にいる敵（黄色ネーム / リンク・引連れ中）
3. **Priority 2**: 他のPTメンバーを直接攻撃している敵（赤ネーム）
4. **Priority 1**: 範囲内にいるその他の有効な敵

※ Priority 3 および 4 の判定では、**「指定釣り役から最も近い位置にいる敵」** を最優先で選択します。
