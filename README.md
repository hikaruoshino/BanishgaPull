# BanishgaPull - FFXI Windower4 Addon for Paladins

**BanishgaPull** は、ファイナルファンタジーXI（Windower4環境）におけるナイト（PLD）向けの自動ターゲット選択＆範囲ヘイト即時獲得補助アドオンです。

多重リンクや範囲狩り、高難易度コンテンツ（オデシー、ダイバージェンス等）において、PTメンバーや指定された釣り役に群がる敵を最速で検知し、範囲魔法「バニシュガ」を即座に叩き込んでヘイトを横取り・固定します。

---

## 🚀 主な機能

* **リアルタイム優先度サーチ**:
  * **Priority 1 (最優先)**: 指定された「釣り役（Puller）」を攻撃している敵（釣り役に一番近い敵を抽出）
  * **Priority 2**: 他のパーティメンバーを攻撃している敵
  * **Priority 3**: 自身から20m以内で最も近くにいる敵（ファーストタッチ・釣り用）
* **最適化された超軽量設計**:
  * 距離計算に2乗比較（`dist <= 400.0`）を用いてCPU負荷を最小化。
* **文字化け・不発防止**:
  * `windower.to_shift_jis` ヘルパーおよび英語呪文表記（`Banishga`）の内部併用により、日本語クライアントでの安定動作を保証。

---

## 📦 インストール方法

1. `BanishgaPull.lua` をダウンロードします。
2. Windower4のフォルダ内に `addons/BanishgaPull/` ディレクトリを作成します。
3. 作成したフォルダ内に `BanishgaPull.lua` を配置します。
4. ゲーム内のチャット欄で以下を実行します：
   ```text
   //lua load banishgapull
   ```

---

## 🎮 コマンド仕様

| コマンド | 説明 |
| :--- | :--- |
| `//bp` または `//bp pull` | 射程20m以内の最適な敵を検索し、ターゲット切り替え＋バニシュガを即時発動 |
| `//bp puller <PlayerName>` | 指定したプレイヤーを最優先保護対象（釣り役）に設定 |
| `//bp puller reset` | 釣り役指定を解除（PT全員を均等監視） |
| `//bp status` | 現在の動作状態と設定中の釣り役名を表示 |
